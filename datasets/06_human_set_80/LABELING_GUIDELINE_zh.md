# 標註指南 — 混亂金融問題外部效度標註集(中文版)

## 目的
每一題,請判斷「一個**正確的金融助理**面對這題**應該怎麼做**」——只憑使用者寫出來的題目判斷。
這個由人類、與系統無關的標籤,是我們拿來評分所有系統(VerifiQuant、R-PAL、CoT)的 ground truth,
用來反駁「trap 是從自家 contract 衍生」的質疑。

## 四個標籤 — 只要標單一字母:**A / R / C / O**
- **A — ANSWER(直接回答)**:資料齊、題意清楚,是標準金融計算,正確回應是**一個數字**。*(良定義、可算)*
- **R — REQUEST-INFO(要求補資料)**:缺了必要的**數值**,助理應該先問使用者要那個特定數字。*(良定義,但缺資料)*
- **C — CLARIFY(要求釐清)**:數字都在,但有一個會**改變答案**的「解讀選擇」;助理應該先問要哪一種解讀
  (或明講假設)。*(選定一種解讀後就能算)*
- **O — OUT-OF-SCOPE(超出範圍)**:題目**根本不是一個「算出唯一數字」的計算**——要建議/意見、要預測,
  或需要這裡拿不到的資料/模型。*(題目本身就不是「算一個數」)*

## 判斷流程 — 由上往下,遇到第一個「是」就停
1. 這題**本身**是不是「算一個數字」?——若是要建議/意見(「我該不該…」「划不划算」)、要預測
   (「會不會漲」),或需要題目給不出的方法/資料/模型 → **O**
2. 題目裡是不是**缺了某個必要數值**(你會用到、但沒給的數字)? → **R**
3. 數值都在,但有一個會**改變答案的「解讀選擇」**?——百分比 vs 小數 · 期初 vs 期末 / 哪一期 ·
   指哪個指標 · 360 vs 365 · 稅前 vs 稅後 / 毛 vs 淨 · 每股 vs 總額 → **C**
4. 其餘——資料齊、無歧義、答案唯一 → **A**

### 大家最容易卡的兩組對比
- **R vs C** — R = 缺一個**數字**(去問那個值);C = 數字都在,只是**要用哪種解讀**不清楚(去問是哪一種)。
- **C vs O** — 用一句話測試:*「如果我可以問使用者**剛好一個**關於解讀的釐清問題,我接下來能不能從已給的
  資料算出**一個確定的數字**?」* **能 → C;不能 → O。**(O 是要建議、要預測、或需要資料/模型——沒有任何
  「解讀釐清」能把它變成一個算出來的數字。)

## 標註原則
1. **只憑題目 + context** 判斷,把自己當成那個助理;不要看任何系統的輸出,也不要想任何系統的設計。
2. **不要從旁邊的數字自行推測沒寫出的值。** 即使題目已貼出一段包含多個數字的表格或摘要,只要公式
   所需的一個關鍵數值沒有提供,仍是缺資料(**R**);理由中請寫明助理應追問哪個特定數值。
3. **使用者的困惑 ≠ 題目的歧義。** 使用者說「我不太會算」但數字都給了、是標準算法 → **A**。他不會算不影響標籤。
4. **標籤是「助理該做什麼」,不是「題目自己給的數字/宣稱對不對」。** 「這個對嗎?」這種驗證題只要資料齊 →
   **A**(助理該算出真值,並指出宣稱是否成立)。例:「新聞說 95% VaR ≈ $3.3,對嗎?[輸入都給了]」→ **A**
   (真正 VaR ≈ $1.65)。
5. **範圍是看「題目」,不是看「你會不會算」。** 不要因為公式很進階、或你要查一下,就標 **O**。只要輸入齊全、
   是確定性計算(duration VaR、債券凸性、選擇權 Greeks)就是 **A**。只有當一個財金人會說「這題**本身**不是
   一個確定計算」(要建議、題目不良定義、或需要拿不到的資料/模型)才標 **O**。
6. 每題一個標籤,附**一句話理由**。真的難以取捨就加 **?**(丟進分歧池,不用硬選)。

## 例子
- **A** — 「營收 500(2022)→ 550(2023),YoY 變化率?」 ·「面額 1,000、年息 5%、3 年、殖利率 4%,價格?」 ·
  「新聞說 VaR ≈ $3.3,對嗎?[輸入都給了]」。
- **R** — 「營收 520、營業成本 390,ROA 多少?」(缺平均總資產) ·「面額 1,000、買價 970,
  貨幣市場收益率多少?」(缺到期天數)。
- **C** — 「把這個 90 天報酬年化」(360 vs 365 基準) ·「成長率多少?」給了好幾年(哪一年的 YoY? 還是 CAGR?) ·
  「給我負債比率」(負債/權益 vs 負債/資產)。
- **O** — 「我該投資這個專案嗎?」(建議) ·「這檔下一季會漲嗎?」(預測) ·「用 Heston 模型定價」(要模擬校準,
  題目沒有可代入的封閉公式) ·「我的 VaR 多少?」但沒給方法也沒給輸入(如問法無法作答)。

> 同一個專案的對比:「這些現金流的 NPV 是多少?」→ **A**;「這裡你要哪個報酬指標?」(IRR vs 簡單報酬,兩個都可算)
> → **C**;「這個專案值得嗎?」→ **O**(這是價值/決策判斷,不是一個數字)。

## 怎麼填
- **請各自開自己的分頁來標。** 在共用試算表裡,把題目分頁複製一份、用你的名字命名,在**你自己的**分頁上標;
  不要動別人的分頁。(如果是用 Markdown/CSV 檔,就直接填 `label` 和 `reason` 兩欄。)
- 填 **A / R / C / O**(難取捨加 **?**)+ 一句理由。**A** 的題若順手註明想算的指標(例:「YoY 變化率」),
  對我後續評分很有幫助。
- 請**獨立標註**——標完之前先不要跟其他標註者對答案。
